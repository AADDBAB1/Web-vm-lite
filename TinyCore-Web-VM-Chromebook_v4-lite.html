Máquina virtual

🌐 Ethernet virtual pronta — será conectada ao iniciar.

Reiniciar só reinicia o sistema (como o botão reset de um PC) — nada é apagado. Parar desliga a VM, mas o disco virtual continua salvo no navegador.

📸 Estado da VM

Disponível quando a VM roda sem disco virtual (modo live CD). Com disco virtual, tudo já é salvo automaticamente.

💽 Disco virtual (instalar e dar boot)

Um disco IDE de até 1,5 GB (/dev/hda no TinyCore, "Disco 0" no Windows). Ele é salvo automaticamente no armazenamento do navegador e sobrevive a reinícios, a Parar e a fechar a aba. Só o que for gravado ocupa espaço.

Verificando disco…

O disco é criado automaticamente na primeira vez que você iniciar a VM. Para trocar o tamanho, apague o disco e crie outro. Escolha Disco rígido (.img) em "Tipo da mídia" para importar uma imagem de disco pronta (até 1,5 GB).

🔌 Pendrive virtual

Os arquivos selecionados vão para um segundo disco FAT16 (/dev/hdb). Ele é montado automaticamente ao iniciar a VM.

🪟 Como rodar uma ISO do Windows

  1. Escolha a ISO em Mídia de boot. ISOs grandes são lidas aos poucos, sem carregar o arquivo inteiro na memória.
  2. Deixe o disco virtual anexado (1,5 GB) e a ordem de boot em CD primeiro.
  3. Clique em Iniciar VM e, quando aparecer "Press any key to boot from CD", clique na tela e aperte uma tecla.
  4. Particione e formate o disco virtual no instalador. Quando o instalador reiniciar o sistema (ou você usar Reiniciar), o disco continua lá; troque a ordem para Disco primeiro (ou deixe em Automática) para dar boot do sistema instalado.
  5. Windows 95 e alguns Windows 98 não têm CD inicializável: carregue um disquete de boot .img no campo Disquete de boot e mantenha a ISO como CD.

Compatibilidade honesta: o v86 emula um PC x86 de 32 bits simples. Windows 95/98/ME/2000/XP costumam funcionar (lentos; o XP fica apertado em 1,5 GB). Windows Vista/7/8/10/11 normalmente não iniciam ou não completam a instalação neste emulador, independentemente do tamanho do disco.

🌐 Como conectar o TinyCore à Internet

Quando a VM inicia com a rede ativada, o TinyCore recebe uma placa Ethernet virtual NE2000. Se o DHCP não configurar sozinho, abra o terminal e execute:

sudo udhcpc -i eth0 e depois teste com ping -c 3 1.1.1.1

Se a interface tiver outro nome, use ifconfig -a. A conexão passa pelo relay público do v86; ela não acessa diretamente a placa Wi-Fi do Chromebook.

💾 Como instalar o TinyCore no disco virtual

  1. Inicie com o disco anexado e abra um terminal no TinyCore.
  2. Particione: sudo fdisk /dev/hda (crie uma partição primária, tipo Linux) e formate: sudo mkfs.ext4 /dev/hda1.
  3. Instale o utilitário: tce-load -wi tc-install e rode tc-install, escolhendo hda1.
  4. Reinicie com o botão Reiniciar; com a ordem Automática, a VM passa a dar boot pelo disco.

Como acessar o pendrive no TinyCore

  1. Selecione os arquivos antes de iniciar a VM (o pendrive é montado automaticamente na hora de iniciar).
  2. No terminal: sudo mkdir -p /mnt/pendrive e sudo mount /dev/hdb1 /mnt/pendrive.
  3. Os arquivos estarão em /mnt/pendrive.

Importante: o navegador não dá acesso direto ao sistema de arquivos do computador. O pendrive virtual é uma cópia dos arquivos selecionados, criada somente dentro da VM.

Emulação por v86. Disco e RAM da VM usam memória do navegador. Para ficar leve em Chromebooks, só os blocos gravados do disco ocupam espaço.
